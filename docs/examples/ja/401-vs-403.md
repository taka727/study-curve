# 401 と 403 の違い

## ✅ 思い出せるか（読む前に）

> 例を見て答えを思い浮かべてから、下の答え合わせを読む。

**例1** ログインせずに、会員だけが使える API を呼んだ。返るのは 401 と 403 のどちら？

**例2** 一般の会員としてログインし、管理者だけが使える API を呼んだ。返るのは？

**例3** 例2 で 403 が返ってきた。その会員の権限が変わらないまま、同じ会員でログインし直せば通るか？

## 🎯 答え合わせ — これを覚えていればOK

- **OK**：**401 は「認証が必要」（認証情報がない、または正しくない）**、**403 は「要求は分かったが、許可しない」**（ログイン済みの会員に権限がないときによく使われる）
- **なぜ**：401 は正しい認証情報を付ければ通る見込みがある。403 は、権限が変わらない限り、同じ会員のまま送り直しても通らない（403 だけでは、本人確認が済んでいるとは限らない）

出典：RFC 9110（15.5.2 401 Unauthorized、15.5.4 403 Forbidden）
