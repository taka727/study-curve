# push 済みのコミットを取り消す

## 🎯 答え合わせ — これを覚えていればOK

- **OK**：push 済みは **`git revert`**（打ち消すコミットを足す）、push 前は **`git reset`**（履歴を戻す。`--soft` なら変更はステージに残る）
- **なぜ**：reset は履歴を書き換えるので、すでに取り込んだ人の履歴と食い違う。revert は履歴に足すだけなので、共有したブランチでも安全
